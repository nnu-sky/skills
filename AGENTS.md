# Repository maintenance

- Canonical skill sources live in `plugins/*/skills/*`; do not maintain duplicate source trees.
- Preserve the user's requested task, existing invocation policies, scientific evidence requirements, and selected plotting backend.
- Resolve helpers relative to the skill directory. Reuse loaded guidance; do not impose repeated permission, mandatory delegation, or exhaustive test flows for routine work.
- Keep host/account credentials and machine-specific defaults in local configuration. Preserve third-party licenses and attribution.
- Check changed skill entrypoints, referenced resources, plugin manifests, and affected scripts. Do not run live training, remote changes, or paid API calls as packaging tests.
- Keep historical venue templates and network measurements explicitly dated; consult current official sources when those requirements affect a live task.
