# 论文写作、画图与检索：使用示例

安装见 [仓库首页](../README.md#给科研朋友的推荐组合)。将下列项目和文件名称替换成自己的材料；无需提供服务器密码或私有访问凭据。

## 1. 论文叙事修改

> 使用 $ml-paper-writing 修改论文 Results 和 Discussion。根据已有表格和证据解释发现及意义，保留混合结果；删去重复过程描述，把必要的实验设置集中到已有协议。局部修改即可，不扩展实验。给出修改前后对照。

示例原文：

> We copied a checkpoint, ran two branches, recorded their gradients at each step, and then measured parameter distances.

如果实验确实只改变反向规则，可改为：

> Changing only the backward rule at a shared forward state produces different gradients and separates the optimization trajectories.

第二句需要对应的受控实验支持。示例展示叙事方式，不提供可直接当成研究结果的证据。

## 2. 论文图表

> 使用 $nature-figure 根据 results.csv 与现有绘图脚本制作论文图。用左右两个子图分别展示主要结果和相对基线的变化，保留所有条件与原有误差定义。沿用现有 Python/R 后端，统一方法配色，删去重复标题和无解释作用的标记。输出可编辑的矢量 PDF/SVG、预览与源脚本，并检查论文最终尺寸下的可读性。不要编造缺失数据。

提供列的含义、单位及均值/标准差的定义；只有这些信息不足以判断时才需要澄清。图注解释结果与必要读图信息，完整复现配置放入实验协议。

## 3. 文献检索与引用核对

> 使用 $nature-academic-search 检索与当前研究问题直接相关的论文，说明检索范围和筛选依据。核对标题、作者、发表信息与 DOI/arXiv 链接，整理方法、主要证据和与本项目的关系，导出 BibTeX。无法核实的条目标明待核实，不编造引用。

提供研究问题、检索主题及需要覆盖的时间范围；普通相关工作检索不扩展为引用影响力审计。

## 4. 可选：训练工程优化

> 使用 $gpu-training-infra 优化当前项目的训练执行效率。先查看现有训练入口和日志，测量一个代表性短窗口；按总耗时贡献和实现成本选择候选。默认保持训练目标和配方，优先工程改动及数学等价重组。保留有效改动后重新测量瓶颈并继续，直到达到目标或剩余收益不值得投入。说明局部与整体收益、显存和必要的正确性检查，将候选与结果记在 research_log.md。

可补充自己的时间预算、显存限制和允许修改的范围。批量、精度或近似算法改变训练含义时，应单独说明取舍。此流程依靠当前项目的实测结果迭代，不预设必然加速或固定优化次数。
