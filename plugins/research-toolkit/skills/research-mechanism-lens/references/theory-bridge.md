# 理论桥接

理论的任务是连接算法操作、机制变量和可检验预测，而不是提高文字的理论感。

## 目录

1. 三对象对齐
2. 操作—机制—理论映射
3. 构造理论链
4. 理论反向约束方法
5. 理论有效性检查

## 1. 三对象对齐

先写清：

\[
\text{算法操作 }T
\quad\longrightarrow\quad
\text{机制量 }M
\quad\longrightarrow\quad
\text{可观察行为 }Y
\]

分别回答：

- \(T\) 在数学上是什么算子或决策？
- \(M\) 能否实际估计、绘图或消融？
- 希望证明 \(M(T(x))\) 具有何种方向性变化？
- 该性质对 \(Y\) 产生什么可检验预测？

优先证明中间性质，不强求从复杂模型直接推出最终性能。

### 从工程现象形成理论

把理论形成理解为观察、解释、方法和实验之间的往返过程，而不是先找一个理论再套方法，也不是方法完成后补一个定理。先看稳定失败和最小有效操作，再识别该操作的数学本质及其最可能改变的机制量；只寻找能够产生可观察预测的中间性质。若实验不支持预测，修改机制解释、方法设计或主张强度，不为保留故事强行解释。

说明理论在当前工作中承担的角色：

- **推导型**：理论目标或约束直接导出算法形式；
- **解释型**：算法先被发现，理论说明它为何可能改善某个中间性质；
- **形式化型**：理论把经验观察写成条件化命题，真正关键的是实验验证前提是否存在。

三种角色都可以有价值，但不要把解释型或形式化型理论写成算法由理论必然推出。

## 2. 操作—机制—理论映射

| 算法操作 | 常见机制量 | 优先理论方向 |
|---|---|---|
| 平均、融合、平滑 | 方差、能量、振荡、导数 | 凸性、詹森不等式、核平滑、算子收缩、偏差—方差 |
| 投影、残差、分解 | 重建误差、子空间泄漏、谱能量 | 正交分解、谱理论、低秩近似、扰动分析 |
| 截断、筛选、门控 | 风险质量、支持集外泄漏、选择偏差 | 风险分解、水平集、选择性推断、稳健统计 |
| 重新加权、归一化 | 条件数、边际、校准误差 | 重要性加权、条件化分析、校准理论、凸优化 |
| 容量或预算分配 | 近似误差、计算代价、边际收益 | 资源配置、拉格朗日优化、率失真、描述长度 |
| 邻域或原型调整 | 局部密度、覆盖率、碰撞率 | 密度估计、几何概率、聚类一致性、覆盖数 |
| 多步更新或粗离散 | 局部截断误差、稳定域、累计偏差 | 常微分方程、数值积分、稳定性、控制理论 |
| 路由、早退、级联 | 风险—成本、停止深度、误拒率 | 最优停止、序贯检验、动态规划、选择性预测 |
| 阈值、拒绝、置信决策 | 第一类与第二类风险、覆盖率 | 假设检验、风险控制、共形预测、决策理论 |
| 多证据组合 | 冗余、互补信息、冲突 | 信息论、集成估计、证据组合、条件独立分析 |
| 正则化或扰动 | 灵敏度、稳定性、泛化差距 | 算法稳定性、鲁棒优化、谱范数界、泛化界 |

映射只是检索入口。选择理论前检查其假设是否符合算法和数据。

## 3. 构造理论链

采用以下强度顺序：

1. **定义**：把机制量形式化；
2. **恒等关系**：说明操作如何分解该量；
3. **方向性命题**：证明不增、收缩、有界或单调；
4. **误差或风险联系**：把机制量连接到行为；
5. **边界条件**：说明结论何时失效；
6. **经验预测**：给出可验证趋势。

一个可信理论故事可写成：

\[
T \text{ 改变 } M
\Rightarrow
M \text{ 的上界或期望改善}
\Rightarrow
\text{在假设 }A\text{ 下，行为风险 }R\text{ 收紧}
\]

明确区分：

- 无条件恒等式；
- 依赖假设的定理；
- 近似解释；
- 经验假说。

## 4. 理论反向约束方法

让理论参与共同设计：

- 为使用凸性，要求权重非负且归一；
- 为获得投影性质，明确内积和子空间；
- 为使用稳定性结果，限制步长或算子范数；
- 为建立资源最优性，明确预算约束和目标；
- 为证明单调风险，限制路径或选择规则；
- 为获得可辨识性，增加最小必要观测。

若为了定理而加入的条件损害实际效果，应报告张力，不要隐藏。

## 5. 理论有效性检查

逐项检查：

1. 理论分析的算子是否就是代码实际执行的操作？
2. 理论量是否被实验测量？
3. 理论量变化时，最终行为是否同步变化？
4. 理论能否区分本方法和一个简单替代方法？
5. 关键假设是否可检查，还是永远无法验证？
6. 结论是否只是显然的凸组合不等式，却被夸成全局最优？
7. 定理是否产生了新的实验预测、设计约束或失败边界？
8. 理论失效时，方法是否仍可能有效？若是，明确理论只解释部分机制。

若以上问题大多无法回答，把理论降级为直觉，并优先补充机制实验。
