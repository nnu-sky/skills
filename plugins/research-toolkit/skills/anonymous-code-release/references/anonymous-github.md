# Anonymous GitHub 操作注意事项

本文件记录 2026-09 实际使用中的经验，不保证平台界面或规则保持不变。入口为 https://anonymous.4open.science/ 。执行时以当前网页为准；不沿用旧的登录状态、权限或仓库状态。

- 私有源仓库可通过平台的 GitHub 只读应用访问。授权时选指定仓库；普通登录与扩大应用读取范围是不同操作。
- 表单通常包括源仓库、分支/提交、匿名标识、自动更新、屏蔽词、链接显示及过期行为。匿名标识不包含账号、姓名或机构。遇到重名只修改本次标识，不覆盖其他发布。
- 关键词屏蔽可能按正则解释；按当前提示确认转义，避免误替换代码。账号和姓名由当前项目提供，不写死在通用 Skill 中。
- 预览中的相对文档链接曾被解析为含源账号的 GitHub raw 地址。可以关闭“Keep links”，但仍必须检查最终匿名页面；一次成功设置不是永久保证。保留必要上游归属文本。
- 发布任务的 READY 状态表示平台准备完成；仍需未登录访问及实际下载验证。公开页面可能异步载入，首次空白不等于空仓库。
- 使用页面公开的下载入口，不猜测后台 API。检查二进制权重是否完整，不能因树中出现文件名就宣称权重下载可用。
- 自动更新关闭时，向私有源推送新提交不会自动更新匿名快照。更新后应记录新的对应版本并复查。
- 到期设为停止访问而非跳回源仓库。维护记录写明日期；没有用户要求时，不因此创建定时任务。

只读源码托管可辅助匿名审稿，但不等于对所有站外关联或身份推断提供绝对匿名保证。避免发布带作者关联的日志、项目维护文件或私有链接。
