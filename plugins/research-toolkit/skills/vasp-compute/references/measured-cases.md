# 历史案例提炼与适用边界

这里保留维护者既有 VASP 与势函数 MD 案例中的定性操作教训。原始实测记录、精确实验表、模型身份和个人远程路径由维护者私有保存，不随本技能分发。本分发不是可独立核验的 benchmark，也不提供新的实测结果或性能承诺；使用者需依据自己的输入、版本、资源和已有证据选择候选。

## VASP：同卡并发与 CPU 预算

- 单任务延迟与整批吞吐可能指向不同配置。比较线程和并发时，让两种路线在相同 GPU/物理 CPU 预算下完成同一结构集；实际 CPU 秒与分配物理核乘墙钟分别记录。
- MPS、NSIM、线程和错峰可能相互影响。局部 CPU 阶段加速可能被并发下其他阶段等待抵消；不要将独立倍率相乘。小幅收益若接近相邻基线波动，不足以支持更复杂默认配置。
- 更高 NSIM 或并发可能增加显存并改变 SCF 路径。核对实际 NBANDS、电子迭代数、启动峰值与真实任务准入；某类输入的余量不能推广为混合队列的全局门槛。
- 采样器依赖进程名时可能漏掉新二进制。核对实际 PID 与 MPS 成员，缺失 CPU 采样不能记为零成本。

## 电子算法、初猜与结果质量

Fast 与 Normal 的能量、力、应力一致性不证明未占据能带同样收敛。需要 DOS、能带或光学性质时，按相应目标验证空态；同一 EDIFF 不保证不同算法的输出逐位等价。

已有兼容 CHGCAR/WAVECAR 可减少部分相近结构的 SCF 工作，但波函数复用不总比电荷复用快。新建参考的计算、写出、复制与等待成本须计入当前批次；不能为了热启动强迫互不相关的任务串行。磁性、DFT+U 或多稳态体系还需核对电子态，收敛本身不是全局最低态证明。

单结构误差与结构间能量差、排序或力变化误差是不同量。近简并趋势直接比较差值，不能以每原子平均误差很小代替目标判断；历史筛选容差不是其他项目的入训标准。

## 交互计算、源码优化与计时

交互式接口可运行不等于短序列更快。对照应采用合理的文件热启动，计入初始化、退出与必要输出；将停止协议的额外步骤排除出目标帧，并保持逐帧任务身份。清理中间 shell 不一定终止 MPI 子链，优先使用接口的正常退出协议。

重复数学量缓存或向量化的微基准收益可能无法转化为完整 DFT 收益。验证依赖与线程隔离、适用泛函分支、尾部屏蔽和内部异常，再检查目标阶段及完整工作量。受限 VASP 源码与补丁留在合法私有环境。

LOOP、LOOP+、内部阶段和 CPU/GPU 时间存在嵌套或重叠。GPU 生命周期重叠不等于硬件同时执行计数；单个 MPS 客户端空档不代表整卡空闲。分析器扰动、超时或未收敛诊断不计入完整 DFT 吞吐，也不能用于推断未经测量的带宽比例。

## MLMD：后端、压缩、精度与启动成本

MACE 等变算子后端、浮点精度、MPS 和批量调用的效果依模型与负载而变。后端转换与首次编译可能抵消短轨迹的稳态收益；不把某种模型的后端配置移植到另一架构。

DeepMD 压缩制品变大不代表计算压缩无效。表格步长与硬件精度是不同维度；粗表误差不必随步长简单排序。冻结模型的 `.float()` 不能证明全部图常量或自定义算子已转换，需核对实际执行路径并保留原模型作为独立参考。

AMP、TF32 或定制矩阵模板需在当前模型上验证收益和新增误差；支持某段外围运算不等于整条路径都使用该精度。单条最快与批量最快可能不同，显存空余也不意味着增加并发仍有收益。

模型实现差、压缩或精度差、相对 DFT 的模型误差、长期统计误差分别报告。相同初态和随机流副本只能作为性能控制，不算独立科学样本；有限短轨迹不证明长期稳定、自由能、virial 或 NPT 可用。

## 迁移与实际应用

先识别真实模型、成熟执行入口及安装顺序。未知自定义算子可能是扩展未注册，不能立即认定权重损坏。实验包装器所需的旧基线文件不一定是可复用接口的依赖，不能伪造参考文件绕过验证。

核对物理 GPU、UUID、锁、监测目标与 CPU 线程设置时机。多卡共享 CPU 域时不能逐卡重复分配核预算；未测全机同时负载时，不用单卡吞吐乘卡数宣称全机结果。

原生后端首调异常在预热后消失，不证明根因已修复。研究入口通过同几何力检查或输出可读，也不意味着生产观察器、恢复和收集已接入。环境检查、短测筛选、完整计算、收集与入训分别保留状态。

具体决策按需阅读 [组合优化](combinations.md)、[势函数 MD](mlip-md.md)、[DeepMD 配置](deepmd-md.md) 或 [服务器应用](md-application.md)。这些教训用于缩小当前任务的必要验证，不要求逐项复现实验。
