# 输入准备与恢复

来源核对：2026-09-13。按任务读取相关段落。目标是产出可检查的输入或一次有理由的恢复，不替代项目科学配方。

## 从目标到输入文件

先读取实际结构、既有 INCAR 和势信息。优先用项目已有输入生成器；已有 ASE/pymatgen 时使用其结构和输入对象，避免自己实现晶胞、元素排序、选择性约束或赝势拼接。生成到用户指定目录或独立尝试目录，核对生成后的元素顺序、坐标、约束和实际参数，不只展示一段未执行代码。

复用旧实验运行器时，检查它在复制输入之后追加、默认设置或覆盖了哪些参数。例如，小体系运行器固定的NBANDS不能直接带入更大结构。运行前核对最终INCAR，启动后再核对OUTCAR的实际值；仅原始输入相同不足以证明实际计算设置相同。

新接入解析或回收接口时，若已有适合的OUTCAR，先用它做一次最小解析/接收调用，核对安装版本的参数类型与返回产物，不为此额外计算DFT。沿用已经验证且未变化的接口时无需重复。计算完成后若仅解析失败，保留输出修复接口并重放解析，避免重算。

| 任务 | 需要落实的选择 | 最小验收 |
|---|---|---|
| 单点能量、力、应力 | 静态离子设置（通常 IBRION=-1、NSW=0）；保留目标应力的 ISIF、所需能量定义 | 完整 SCF，输出结构与输入对应，能量/逐原子力/所需应力可解析 |
| 固定晶胞弛豫 | 哪些原子可动，离子算法和步长，EDIFFG 停止条件 | 电子收敛与离子收敛分别检查；跑满 NSW 不是弛豫成功 |
| 晶胞弛豫 | 晶胞自由度、外压、应力和 Pulay 误差控制 | 晶胞/应力收敛及所需精度；表面真空方向不能随意参与三维体相优化 |
| AIMD | 系综、温度、时间步长、恒温/压方法与约束；需要的轨迹输出 | 每步 SCF 状态、实际步数、温度/能量行为；能量漂移按系综解释 |

从晶胞倒格矢和目标量选择 k 点。表面通常对面内采样和真空分别判断；孤立分子也需检查超胞相互作用。已有 KPOINTS 时检查它与 KSPACING 的实际作用，不把 Gamma-centered 多点网格当成单 Γ 点。

POTCAR 按 POSCAR 元素顺序和指定泛函/势选择，记录 TITEL、价电子/势版本及 ENMAX。势缺失时交付其他已完成输入和准确的势需求，停止于运行前；不下载受限势或用空 POTCAR 代替。ENCUT 建议依赖所选势及目标量收敛，不能从元素名直接保证 400 或 520 eV 足够。[势准备](https://vasp.at/wiki/Preparing_a_POTCAR)、[ENCUT](https://vasp.at/wiki/ENCUT)

未知金属/绝缘体时不要默认金属型展宽；磁性、DFT+U、SOC 按科学问题确定。没有磁性依据的 ISPIN=1 可能排除相关电子态；MAGMOM 是初猜而非已知最终磁序。展宽改变时同时核对输出能量定义和力。[展宽](https://vasp.at/wiki/ISMEAR)、[磁性初猜](https://vasp.at/wiki/MAGMOM)

没有精度协议时，先给带理由的起点与局部收敛方案。对目标能量差、最大力分量或应力设所需容差，分别提高截断、k 点或电子收敛精度，直到满足用途；无需每次执行全套收敛扫描。优化标签生成时复用已确认协议，不为显示提速而降低精度。[EDIFF](https://vasp.at/wiki/EDIFF)、[结构优化](https://vasp.at/wiki/Structure_optimization)、[MD](https://vasp.at/wiki/Category:Molecular_dynamics)

## 有证据的恢复

先从 stdout、OSZICAR、OUTCAR 尾部、进程退出码和资源记录确定失败阶段。错误处理器优先复用现有 Custodian；只有明确匹配的处理器才启用，保存原输入、修改、错误与新尝试的对应关系。[Custodian 处理器源码](https://github.com/materialsproject/custodian/blob/master/src/custodian/vasp/handlers.py)

| 观察 | 首先处理 | 完成条件 |
|---|---|---|
| 程序未开始，库/MPI/变体错误 | 检查实际二进制、动态库、构建能力和启动命令 | 原输入能够进入预期计算，不能靠改科学参数掩盖环境错误 |
| CUDA OOM/系统 OOM | 确认 GPU 或主存、并发与初始化峰值；减少并发或选择能容纳任务的资源 | 原精度任务完成；不自动削减 ENCUT/NBANDS |
| SCF 到 NELM，残差震荡 | 先看结构/势/空带/占据，再按残差选择混合或求解算法；单纯增 NELM 只适合仍在稳定改善的情况 | 新尝试达到电子收敛并核验能量、力及相关磁态 |
| 输出完整但回传失败 | 按现有任务身份重传并确认工作流接收 | 收集凭证或原系统接收记录；不再次启动 DFT |
| 弛豫/MD 提前结束或中间某步 SCF 失败 | 确认最后有效结构、步号、是否需要重启文件 | 明确续算起点，保留此前无效步骤标记 |

电子收敛失败的具体参数要查[官方诊断](https://vasp.at/wiki/Troubleshooting_electronic_convergence)和[ALGO](https://vasp.at/wiki/ALGO)，不机械叠加 AMIX/BMIX 等改动。同一原因的一次调整仍无改善时重新诊断；不让自动修复无限运行。固定电荷后处理不是新结构的完整 SCF。多稳态体系的热启动和冷启动可能收敛到不同解，要按实际研究问题判断，不能仅凭达到 EDIFF 证明全局电子基态。
