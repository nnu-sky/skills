# 势函数 MD：选择、执行和优化

## 从目标和实际入口开始

先核实用户当前模型与引擎。DP-GEN2项目通常需要检查实际DeepMD权重和LAMMPS入口；此时转到 [DeepMD长程模拟](deepmd-md.md)。下面的MACE算子/精度案例只支持MACE分支，不作为其他势函数的配置依据。

区分 VASP AIMD、机器学习势 MD、经典势 MD。用户的自训练 MACE 权重可以通过同一个 MACECalculator/MD 入口运行，不需要重写积分器。其他自有势优先使用已经实现的 ASE Calculator、LAMMPS pair style 或 TorchSim ModelInterface；没有接口时只补适配器及力/单位验证，不假称任意函数都能被当前服务接受。

先发现项目已有工具，读取能力、输入 schema 和资产信息，使用注册结构和模型。核对元素覆盖、模型训练域与目标体系、能量/力单位、周期边界、固定原子、系综、温度、时间步和输出要求。不能因为模型可加载就证明它适合反应或长期模拟。模型预测、偏置力和真实 DFT 标签分开保存。固定 Cu 的表面模拟不得在迁移引擎时丢失约束。

## 少量对照，定位真实开销

在已授权的性能优化中，使用实际结构、同一模型与初始状态，按需先跑少量步。分别测模型加载/转换/编译、预热后的力计算、包含积分/检查/轨迹输出的完整 MD。需要时用 Python profiler 区分模型调用、建邻居表、CPU/GPU 数据搬运、安全检查、候选选择和 I/O；CPU profile 含 GPU 等待，不是 CUDA 时间线或内核占比。

候选按瓶颈选，不要求全部扫描：

- **等变算子**：检查已安装 MACE 是否支持 `enable_cueq=True`。cuEquivariance 是替换算子实现；记录转换成本、兼容模型、力差和显存。已开启就不能再次算作新增收益。
- **数值精度**：单独比较 float64/float32，再验证组合。保持同一权重、结构和物理设置；默认不引入 BF16/FP16。用固定几何能量/力对照以及短 NVE 能量变化筛选。误差标准来自目标量，MLMD 数值差不是相对 DFT 的模型误差。
- **CPU 预算**：少量比较 1/2/4 线程、绑定与 BLAS/PyTorch 线程上限。线程数受实际分配的物理核约束；多轨迹总 CPU 预算保持一致。不要把所有线程都配置为机器总核数。
- **单卡多轨迹**：比较相同轨迹集合的顺序运行、普通多进程及 MPS，先少量并发；同卡时检查显存和 CPU 竞争。模型转换后应复用长寿命进程，避免为每几步重复加载权重。MPS 必须确认任务实际连入专用服务，结束后只清理本次专用服务。不会默认给 MLMD 套用 VASP 的并发数或收益。
- **批量推理/模拟**：TorchSim 可将多轨迹状态与模型调用批量化，可能减少多个 Python 进程重复发射的开销。先核对版本/Python、模型接口、边界与约束、温控器、轨迹拆分；在隔离环境中测试。批量中每条轨迹保持独立身份与随机状态，不让邻居跨体系连接。仅查阅文档不能报告已实现或已加速。
- **大规模单轨迹**：如果建邻居表或原子域划分占主导，考察 LAMMPS ML-IAP/Kokkos、GPU 邻居表；如果 GPU 发射开销突出，考察 MACE 支持的 compile/padding/CUDA graph。先检查特性支持与编译代价，不为短任务默认编译整个软件栈。

## 接入与验收

保持已有采样入口，新增后端/线程等必要选项时，同时更新服务白名单、schema、实际科学函数、effective settings 和必要测试。缺少加速依赖应明确失败或选择已经验证的原后端，不静默宣称启用。不要为了更漂亮的基准删除力/温度保护、改变时间步或取消用户要求的检查点与输出。若 JSON 序列化是热点，可以先比较紧凑编码与缩进编码，保留相同字段、每步频率、原子替换和旧检查点兼容性；不要把序列化耗时全部归因于磁盘速度。

至少检查：固定几何力和能量一致性、有限短轨迹的积分稳定性、约束/周期边界、失败与恢复、输出仍为未标注结构。有随机恒温器时保持种子规则；不同实现的随机序列/长期混沌轨迹不要求逐点重合，但不能据此跳过物理统计验证。短测通过只支持配置筛选，不证明自由能、反应速率或长期稳定性。

主要指标为相同 GPU/CPU 总预算下的**总有效轨迹步/秒**或**合计模拟 ps/小时**，固定时间步、模型、结构和输出要求；同时给每条轨迹延迟、启动与预热成本、显存测量口径、力差和能量变化。预热后的吞吐不能当成整个任务墙钟；多项独立收益不可直接相乘。

## 主要依据

- [MACE ASE MD](https://mace-docs.readthedocs.io/en/latest/guide/ase.html)：复用 ASE 积分器与模型计算器。
- [MACE cuEquivariance](https://mace-docs.readthedocs.io/en/latest/guide/cuda_acceleration.html)：可选 CUDA 算子后端，实际支持以安装版本为准。
- [TorchSim 项目](https://github.com/TorchSim/torch-sim) 与 [批量状态和自动分批](https://torchsim.github.io/torch-sim/user/overview.html)：批量模型调用、积分、内存预算。
- [MACE LAMMPS ML-IAP](https://mace-docs.readthedocs.io/en/latest/guide/lammps_mliap.html)：GPU/多 GPU 与构建兼容性。不同文档可能描述不同代接口，按实际版本确认。

机器、模型路径、CPU 编号、专用 MPS 路径和测量结果放项目实验记录，不成为跨用户默认值。

可按需查阅 [案例与适用边界](measured-cases.md) 中的 MLMD 定性教训；原始证据由维护者私有保存，不要求新用户先有历史结果。
