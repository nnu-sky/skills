# 实验设计与决策

## 授权模式

- 只读分析：读取代码、生成候选和推荐后停止。
- 自主短测：自动选择一个首选候选，完成最小实现、测试和短程对照。
- 指定候选：只测试用户指定的方法，不顺带加入其他技巧。
- 多候选比较：只有用户明确要求时才最多测试两个，不自动展开网格。
- 完整训练：只有用户明确授权完整预算时执行；短测授权不自动扩展为长训练。

## 建立可比实验

1. 优先复用同代码、同协议、同训练进度的已有锚点。
2. 一次只改变候选声明的因素；联动变量作为一个完整配方命名。
3. 保持数据、种子、评价协议和训练进度可比。短程比较沿用原完整调度，只在指定进度停止，不能因缩短训练而悄悄改变余弦或其他调度曲线。
4. 长训练前用临时检查点跑通训练、保存、加载、正式评价和结果写出。
5. 记录训练时间、显存、损失、项目主要指标和异常；训练损失定义改变时不要直接比较绝对值。

## 短测决策

- 数值错误、显存不足、持续溢出或明显退化：自动停止并标记“已拒绝”。
- 项目主要指标明显改善：标记“初步验证”，报告完整训练成本并等待授权。
- 差异很小或指标方向混合：标记“暂时无法判断”，说明延长训练或调整强度的选项。
- 短测只有训练损失、没有项目主要指标：只能证明链路可用，不能称为涨点。

用户已经授权完整训练时，可按照预先说明的门禁继续；否则不要自行占用更多 GPU、增加轮数、改数据划分或扩大候选组合。

## 报告

同时报告锚点、实际改动、环境、种子、训练进度、墙钟、主要指标差值、成本、风险和结论边界。外部论文、短链路、固定步、短程训练和完整训练必须分开标记。
