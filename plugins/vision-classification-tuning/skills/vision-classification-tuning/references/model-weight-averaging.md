# 模型权重平均

## 先检查项目

在提出 EMA 或 SWA 前记录：

- 真正成功的 `optimizer.step()` 位置；
- 每轮与总更新次数、批量和更新间隔；
- 学习率预热、主调度和训练结束时点；
- 模型是否含批归一化，缓冲区如何处理；
- 原始模型与平均模型如何分别评价和保存；
- 额外显存、训练时间和检查点成本。

EMA 只在成功的优化器更新后推进。被混合精度跳过的更新和梯度累积中的微批不计入 EMA 时间。

## 用训练窗口解释衰减率

设每隔 `k` 个成功更新执行一次 EMA，衰减率为 `β`：

```text
EMA 更新次数半衰期 = ln(0.5) / ln(β)
成功优化器更新半衰期 = k × ln(0.5) / ln(β)
周期半衰期 = k × ln(0.5) /（每周期成功更新数 × ln(β)）
```

批量、卡数、梯度累积或数据集大小改变后，重新换算；不要直接复制其他项目的 `0.999` 或 `0.9999`。

## 候选选择

- 后期结果波动且基础配方已经确定：EMA 是优先候选。
- 训练很短或每轮更新很少：慢 EMA 可能长期滞后，应选择更短窗口或不使用。
- 需要平均训练末段多个解：可以考虑 SWA，但它通常还需要匹配学习率策略。
- 项目使用批归一化时，明确选择平均缓冲区、复制当前缓冲区或训练后重算；不要只平均参数却忽略统计量。

默认只比较原始模型与一个根据目标周期半衰期计算的 EMA 候选。只读分析时等待用户选择；用户已授权自主短测时可直接运行该候选，但不自动搜索多个衰减率、启动时点和缓冲区策略。

若实现成本允许，在同一次训练中同时保存在线权重和 EMA 权重，并用相同评价种子、数据和指标配对比较。这样可以隔离随机初始化与数据顺序差异；EMA 未优于在线权重时保留负结果，不因其他项目曾有效而继续自动搜索衰减率。

## 记录边界

把具体项目的衰减率、更新次数、半衰期、收益和负结果写入项目报告。技能只保存换算方法与选择条件，不沉淀脱离训练预算的固定衰减率。
