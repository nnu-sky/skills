# 候选发现与排序

## 主动候选池

每次读取项目后主动检查下列方向，不要求用户提前点名：

1. 学习率、预热、余弦／阶梯调度、训练预算；
2. 批量与学习率联动、梯度累积和每轮更新次数；
3. 优化器、动量、权重衰减和参数分组；
4. 标签平滑及其他损失正则化；
5. 基础增强、RandAugment、TrivialAugment Wide、随机擦除；
6. MixUp、CutMix 及软标签兼容性；
7. EMA、SWA 和检查点选择；
8. 类别不平衡、采样和类别权重；
9. 预训练、分层学习率和微调策略；
10. 当前方法特有的温度、损失权重、原型或教师动量、队列和记忆窗口。

候选池用于思考，不要求全部展示或运行。项目没有某类结构时跳过对应方向。

## 排序方法

按以下因素综合排序：

1. 与代码和当前现象的匹配程度；
2. 是否与标签、视图、损失和状态更新兼容；
3. 当前项目、相近成熟实现或一手研究的证据强度；
4. 预期收益相对于实现和训练成本；
5. 是否容易单独归因；
6. 是否与项目已用方法重复作用。

优先级示例：

| 代码或现象 | 优先方向 |
| --- | --- |
| 固定学习率、衰减点不合理或初期不稳 | 学习率、预热、调度 |
| 训练指标高而验证明显落后 | 标签平滑、轻量增强、权重衰减 |
| 数据增强很弱 | 一种成熟增强策略 |
| 欠拟合或训练不足 | 学习率、预算、减弱过强正则化 |
| 后期指标或检查点波动 | EMA 或 SWA |
| 批量变化 | 学习率、预热、总更新次数和按步状态 |
| 类别明显不平衡 | 采样、类别权重，必要时 Focal Loss |
| 预训练骨干和新分类头 | 分层学习率和短预热 |
| 对比、度量或原型目标 | 温度、损失权重、状态动量及兼容的局部软目标 |

## 展示与推荐

内部完成候选池后，只向用户展示三到五个最相关方向，并明确推荐一个首选。不要把完整菜单交给用户自行筛选，也不要声称首选必然有效。

推荐时说明可以组合与不能同时首次加入的候选。默认先测试单项；只有单项已产生正向项目证据，才建议小规模组合。
