# 实验室服务器运维

## 执行

权限不足且任务已授权管理员操作时，复用已有授权和本地管理配置。普通 SSH 执行优先使用 `lab-server-remote`；本技能重点处理跨账号、权限和认证回退。

- 当前主机需要管理员权限时，直接使用本机管理员配置，不经过 SSH。
- 操作另一台服务器时，直接执行目标命令，不单独建立测试连接。

远程操作使用：

```bash
scripts/run-remote.sh <服务器键> <admin|user> [--sudo-user <用户>] -- '<命令>'
```

- 首次配置或映射缺失时读取 [本地配置](references/configuration.md)；示例别名必须由使用者配置。
- 使用本地配置中的 SSH 别名。
- 普通账号选择 `user`，管理账号选择 `admin`。
- 需要在远程目标上以另一账号读取数据或修改权限时使用 `--sudo-user`。
- 上传、下载、复制或同步时，读取 [文件传输](references/transfer.md)。

## 验收

- 查询任务：报告目标服务器、账号和关键状态。
- 变更任务：说明改动、验证结果、产物位置和未解决风险。
- 传输任务：核对来源、目标、文件数量和大小或校验值。
